## Directory Purpose

### `/src` - Source Code
- `train.py`: Trains ML model on historical data
- `predict.py`: Generates yield predictions + risk alerts
- `analyze_data.py`: Explores dataset statistics & creates visualizations
- `fdata.cpp`: Interactive C++ tool for farmer data input

### `/data` - Data Files
- `data.csv`: Historical dataset from South African farms (training data)
- `input.txt`: Current farmer inputs (auto-generated by `fdata.cpp`)

### `/models` - ML Models
- `model.joblib`: Trained model (binary format, created by `train.py`)

### `/output` - Generated Outputs
- `results.csv`: Farmer-friendly predictions (shareable via WhatsApp/email)
- `yield_forecast.png`: Chart showing rainfall vs predicted yield

### `/docs` - Documentation
- `SETUP.md`: Installation instructions
- `USAGE.md`: How to use the app
- `PROJECT_STRUCTURE.md`: This file

## Workflow

```
1. Data Input (fdata.cpp)
   ↓
2. Process Input (predict.py reads data/input.txt)
   ↓
3. Load Model (models/model.joblib)
   ↓
4. Generate Predictions
   ↓
5. Output Results (output/results.csv, output/yield_forecast.png)
   ↓
6. Share with Farmers
```
